# RETAIL-DATA-AGENT-TASK-
In this task i created a Data Agent in Databricks - my Agent name is Sales Lens Agent , the role of this agent is to quickly answer business related questions as accurate as possible based of the data is has been provided with.
I reviewed the data beforehand to assist format appropriate business questions to assist analyse the data and provide the store CEO with insights to make better informed dicisions.
The dataset contains 1000 transactions from a retail store, covering from January 2023 to January 2024. Each row represents a single purchase made by a customer, and the data covers three product categories across a various customer base.
i gave the agent specific instrustions to follow when answering questions , with constrains of not fabricating any number or catagories as this will provide false insights - all must be from the retail sales dataset provided to the agent. 
I tested the agent with 10 questions and validated 3 questions by running SQL queries and Manual table preview to check the accuracy of the agent answers vs the data contained in the table.
From the information provided by the agent , i listed a few insights based on the findigs.
I also provided some recomandations to the business going forward.
